# MOK Student

> **Learn. Build. Share.**

MOK Student is a student-led community where students explore technology by building real projects., experimenting with new ideas, and learning together.

We believe you don't need to be an expert to start building. You just need curiosity, a willingness to learn, and the courage to make mistakes.

## 🚀 What We Do

* 💻 Build real projects
* 🧠 Learn through practice
* 🤝 Collaborate with other students
* 🧪 Experiment with new technologies
* 🌱 Share knowledge and grow together

## 🛠️ What You'll Find Here

Our GitHub organization contains projects, experiments, learning resources, and collaborative work created by students.

Every repository represents something we're learning, building, testing, or exploring.

## 💡 Our Philosophy

**Learn → Build → Break → Fix → Repeat**

We don't wait until we know everything.

We build, discover what we don't know, and learn along the way.

## 🌱 Join the Journey

Whether you're writing your first lines of code or already building complete projects, there's always something new to learn.

**Made by students. Built with curiosity.**
